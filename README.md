# 🍔 My Food App

A beautiful, fast, and modern Food Delivery App built using Flutter. This project is a complete solution for browsing delicious meals, managing food carts, and experiencing a smooth food ordering flow.

---

## ✨ Key Features

* 🏠 **Interactive Home Screen**: Easily browse trending dishes and restaurant banners.
* 🍕 **Smart Categories**: Filter food items by Pizza, Burgers, Desserts, and Drinks.
* 🛒 **Dynamic Cart System**: Add, remove, and update food quantities in real-time.
* 🎨 **Clean UI/UX**: Designed with a modern, eye-catching, and user-friendly layout.
* 🚀 **Fast Performance**: Optimized widget tree for smooth 60fps scrolling.

---

## 🛠️ Tech Stack & Tools

* **Framework:** Flutter (Dart)
* **IDE:** VS Code 
* **Version Control:** Git & GitHub

---

## 🚀 How To Run This Project

Follow these simple steps to run the app on your local machine:

### 1. Clone the Repository
```bash
git clone https://github.com
```

### 2. Move into the Project Directory
```bash
cd my_food_app
```

### 3. Install All Dependencies
```bash
flutter pub get
```

### 4. Run the App
```bash
flutter run
```
